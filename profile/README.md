# UNOSELAB

UNOSELAB is a research group at the University of Nebraska at Omaha focused on
software engineering, program analysis, and AI-assisted software development.

## Research Focus
- Program analysis and software evolution
- Software correctness and security
- AI- and LLM-assisted software engineering
- Program understanding and transformation
- AI-assisted programming education

## Repositories
This organization hosts research prototypes, datasets, and teaching materials
associated with UNOSELAB projects. Some repositories are public; others are
private for internal development.
